# AI Mock Interview

A modern AI-powered mock interview platform built with Next.js, TypeScript, and Google Cloud AI services. This project allows users to practice interviews, get AI-generated feedback, and interact with a real-time interview assistant.

---

## Features

- Real-time mock interviews with AI assistant  
- Voice-to-text support for speaking answers  
- AI-powered feedback using Google Generative AI and OpenAI APIs  
- User authentication and management with Clerk  
- Form handling and validation using React Hook Form + Zod  
- Multi-database support using Prisma + Neon Database (PostgreSQL)  
- Dark/light mode support with Next Themes  
- Fully responsive UI using Tailwind CSS, Radix UI, and Framer Motion  

---

## Tech Stack

### Frontend
- Next.js 15  
- React  + TypeScript  
- Tailwind CSS + tailwindcss-animate + tailwind-merge  
- Framer Motion for animations  
- Lucide React icons  

### Backend / APIs
- Prisma ORM with Neon Serverless Database  
- Google Generative AI SDK  
- OpenAI API via `openai` and `openrouter/sdk`  
- Axios for API requests  

### Authentication
- Clerk for user authentication and management  

### Utilities
- React Hook Form + Zod for validation  
- react-hook-speech-to-text for voice input  
- react-hot-toast for notifications  
- react-webcam for video capture
